# 知識庫

自分専用の、シンプルな知識データベースです。外部サービスやアカウントは不要で、データはブラウザの IndexedDB に保存されます。

## 主な機能
- タイトル・本文・タグ付きメモ
- 全文検索、タグ絞り込み、更新順/作成順/タイトル順/お気に入り順
- ピン留め、お気に入り、ランダム表示
- 自動保存
- タイトル/本文/全部のコピー
- クリップボードから新規作成
- 画面下の「＋ すぐ追加」からクイック保存
- Androidの共有メニューからタイトル・本文・URLを受け取ってクイック保存
- 複製、ゴミ箱、復元、完全削除
- 見出し/太字/箇条書き/チェックボックス用の入力補助
- URL自動リンク
- 画像添付（1枚10MBまで）
- 関連メモ
- JSONバックアップの書き出し/読み込み
- ライト/ダーク/端末設定連動
- PWA / オフライン対応

## 起動方法
PWAやクリップボード機能を正しく使うには、`file://` で直接開くのではなくHTTP/HTTPSで配信してください。

### PCで確認
このフォルダで次を実行します。

```bash
python -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

### GitHub Pages
このフォルダの中身をGitHubリポジトリへアップロードし、Settings → Pages で公開元を指定すると、スマホからURLで利用できます。ブラウザの「ホーム画面に追加」または「アプリをインストール」を使ってPWAとしてインストールできます。

## Androidの共有から追加
PWAをインストールすると、対応するAndroid/Chrome系環境では共有先に「知識データベース」が表示されます。WikipediaやWebページ、他アプリで「共有」→「知識データベース」を選ぶと、共有されたタイトル・文章・URLが画面下のクイック入力に入ります。「保存」でそのまま登録できます。

既に旧版をインストール済みで共有先に表示されない場合は、まず設定からJSONバックアップを書き出してください。その後、最新版をGitHub Pagesへ反映し、必要に応じてPWAを再インストールしてください。

## データについて
ブラウザのサイトデータを削除すると端末内のメモも消えるため、定期的に設定画面からJSONバックアップを書き出してください。別端末への移行もJSONの書き出し→読み込みで行えます。
